This project focused on analyzing the official CPI Inflation Dataset of 10 years from 2013-2023 using Excel and showing the inflation trends across different years and different categories.
Initial steps include data cleaning, making it consistent, and dealing with missing values.
The case study further goes on to find Y-O-Y inflation trends and showcase the same on a line chart.
Month-on-month changes in prices of different categories were analyzed and depcited using line graph.
Further, analyzed the impact of Covid-19 pandemic on the inflation trends in India.
